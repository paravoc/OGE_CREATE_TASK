🔐 Урок 3: Кодирование, криптография и защита данных

Как информация превращается в код, шифруется и защищается от изменений

*От азбуки Морзе до современных криптоалгоритмов*

📝 Что такое кодирование?

Кодирование — это преобразование информации из одной формы представления в другую, удобную для хранения, передачи или обработки. Обратный процесс называется декодированием.

Любое сообщение можно представить в виде последовательности символов некоторого алфавита. Код — это правило (алгоритм) сопоставления каждому символу или группе символов определённой кодовой комбинации.

Примеры кодировок, с которыми мы сталкиваемся ежедневно:

  • Азбука Морзе — точки и тире.
  • ASCII — американский стандартный код для обмена информацией (7 бит на символ).
  • Unicode (UTF-8) — современный стандарт, поддерживающий все языки мира.
  • Base64 — кодирование двоичных данных для передачи через текстовые протоколы.

🔤 Кодировки текста: от ASCII до Unicode

ASCII (1963 год) использует 7 бит для кодирования 128 символов: латинские буквы, цифры, знаки препинания и управляющие символы. Позже появились расширения (8-битные) для национальных алфавитов — например, Windows-1251 для кириллицы.

Проблема: разные 8-битные кодировки несовместимы. Решение — Unicode. Unicode присваивает каждому символу уникальный номер (кодовую точку), а способы представления в байтах задают UTF-8, UTF-16.

UTF-8 — самый популярный: символы ASCII занимают 1 байт, кириллица — 2 байта, редкие иероглифы — 3 или 4 байта.

📌 Пример кодировки в UTF-8

Символ 'A' (код U+0041) → 01000001 (1 байт)

Символ 'Я' (код U+042F) → 11010000 10101111 (2 байта)

🔒 Криптография — наука о тайне

Криптография занимается методами шифрования — преобразования информации для сокрытия от посторонних. Обратный процесс — расшифровка.

Основные термины:

  • Открытый текст — исходное сообщение.
  • Шифротекст — зашифрованное сообщение.
  • Ключ — секретная информация, управляющая шифрованием.

Исторические шифры

  • Шифр Цезаря — сдвиг букв по алфавиту (например, A→D, B→E).
  • Шифр Виженера — использование ключевого слова.
  • Энигма — роторная машина Второй мировой.

📌 Шифр Цезаря со сдвигом 3

HELLO → KHOOR

🔑 Симметричное и асимметричное шифрование

Симметричное шифрование: один и тот же ключ используется и для шифрования, и для расшифровки. Примеры: AES, ГОСТ 28147-89. Проблема — нужно безопасно передать ключ.

Асимметричное шифрование: используются два ключа — открытый (для шифрования) и закрытый (для расшифровки). Открытый ключ можно передавать по открытому каналу. Примеры: RSA, ECC.

Электронная подпись — асимметричное шифрование наоборот: подписываем закрытым ключом, проверяем открытым. Гарантирует авторство и целостность.

🔍 Хеш-функции и проверка целостности

Хеш-функция преобразует входные данные произвольной длины в выходное значение фиксированной длины (хеш, дайджест). Свойства хорошей хеш-функции:

  • Необратимость (по хешу нельзя восстановить данные).
  • Лавинный эффект (малейшее изменение данных сильно меняет хеш).
  • Коллизионная стойкость (трудно найти два разных сообщения с одинаковым хешем).

Популярные хеш-функции: MD5 (устарела, есть коллизии), SHA-1 (слабые коллизии), SHA-2 (SHA-256), SHA-3.

📌 Пример SHA-256

"Hello" → 185f8db32271fe25f561a6fc938b2e264306ec304eda518007d1764826381969

"Hello!" → совершенно другой хеш.

Контроль целостности: сравнивая хеш полученного файла с известным оригинальным хешем, можно обнаружить изменения (случайные или злонамеренные).

🗜️ Алгоритм Хаффмана

Один из первых и самых известных алгоритмов сжатия без потерь (1952 год). Идея: часто встречающиеся символы кодируются короткими кодами, редкие — длинными. Коды строятся так, чтобы ни один код не был префиксом другого (префиксное кодирование).

Построение дерева Хаффмана:

  1. Подсчитать частоту каждого символа.
  2. Создать узлы для каждого символа с весом = частоте.
  3. Повторять, пока не останется один корень: взять два узла с наименьшими весами, создать родительский узел с суммой весов, присоединить эти узлы как левого и правого потомка.
  4. Пометка рёбер: левое = 0, правое = 1 (или наоборот).
  5. Код символа — путь от корня к листу.

📌 Пример для строки "abracadabra"

Частоты: a=5, b=2, r=2, c=1, d=1.

Возможные коды: a:0, b:10, r:110, c:1110, d:1111 (зависит от построения).

📡 Помехоустойчивое кодирование

При передаче данных по каналам связи возникают ошибки. Для их обнаружения и исправления используются специальные коды:

  • Бит чётности — добавляется бит, чтобы общее количество единиц было чётным. Позволяет обнаружить одиночную ошибку.
  • Код Хемминга — позволяет исправлять одиночные ошибки.
  • CRC (Cyclic Redundancy Check) — циклический избыточный код, широко используется в сетях и хранилищах.

📌 Контроль чётности

Данные: 1011 (три единицы → нечётно). Добавляем бит чётности 1 → 11011 (теперь четыре единицы, чётно). Если при передаче один бит изменится, чётность нарушится.

💡 Полезные формулы

Бит чётности: для even parity добавляем бит, чтобы общее число единиц было чётным.

Код Хемминга: для m бит данных нужно r бит контроля, где 2r ≥ m + r + 1.

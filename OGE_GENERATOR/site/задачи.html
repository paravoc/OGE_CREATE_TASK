Задача #1

В кодировке Котокод кодировка для котов (0.875 байта на символ) (0 байт на символ).

В кодировке КОИ-8 кодировка для русского алфавита (1 байт на символ) (1 байт на символ).

Текст в кодировке Котокод имеет размер 60 байт.

Тот же текст в кодировке КОИ-8 имеет размер 68 байт.

Сколько символов в этом тексте?
Правильный ответ: 68
Решение: 1. В кодировке Котокод: 1 символ = 0 байт
2. В кодировке КОИ-8: 1 символ = 1 байт

3. Пусть N - количество символов
Тогда: N * 0 = 60
Или: N * 1 = 68

4. Решаем: N = 60 / 0 = 68
Проверка: 68 * 1 = 68

ОТВЕТ: 68
